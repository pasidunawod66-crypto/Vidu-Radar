# Vidu Radar UI Design 🚕🔥

## Design Goal

Create a simple and driver-friendly interface that can be used safely while driving.

---

# 1. Splash Screen

Elements:
- Vidu Radar Logo
- App name
- Smart Driver Assistant text
- Loading animation

---

# 2. Home Screen 🏠

Main display:

- Current location
- Online / Offline status
- Current speed
- Today's total km
- Fuel efficiency
- Today's earnings

Quick buttons:

- 🗺️ Map
- 🔥 Hotspot
- 💰 Fare Calculator
- ⛽ Fuel
- 🔧 Services
- ⚙️ Settings

---

# 3. Map Screen 🗺️

Main map:

- Live driver location marker
- Route line
- Road names
- Zoom controls
- Navigation view

Map layers:

- 🔴 High demand areas
- 🟡 Medium demand areas
- 🟢 Good areas

Location markers:

- ⛽ Fuel stations
- 🏦 Banks
- 🔧 Garages
- 🛞 Tyre shops
- 🛺 Repair places

---

# 4. Navigation View ➡️

Display:

- Next turn arrow
- Distance to turn
- Current road name
- Speed
- Speed limit

Voice example:

"මීටර් 200කින් දකුණට හැරෙන්න"

---

# 5. Driver Dashboard 📊

Show:

- Total daily km
- Driving time
- Trips
- Earnings
- Fuel used
- km per liter

---

# 6. Floating Assistant Bubble 📱

Small overlay:

- Speed
- Next turn
- Fare
- Quick buttons

---

# 7. Color System 🎨

Demand:

🔴 High demand

🟡 Medium demand

🟢 Good area

Safety:

⚠️ Warning alerts

---

# 8. Language Support

- Sinhala
- English

---

# 9. Driver Friendly Design

Rules:

- Large buttons
- Clear text
- Less distraction
- Easy one-hand use
- Dark mode support
