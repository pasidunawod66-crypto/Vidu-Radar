# Vidu Radar App Flow 🚕🔥

## User Journey

The app flow is designed to be simple and easy for drivers.

---

# 1. App Start 🚕

Flow:

Open App
↓
Splash Screen
↓
Check Login Status
↓
Home Screen

---

# 2. First Time Setup ⚙️

Driver enters:

- Name
- Vehicle type
- Fuel type
- Fuel price
- Average km/L
- Language selection

Then:

Save settings
↓
Open Home Screen

---

# 3. Home Screen 🏠

Driver can see:

- Current location
- Online status
- Speed
- Today's km
- Fuel status
- Earnings summary

Actions:

- Open Map
- Check Hotspots
- Calculate Fare
- View Dashboard
- Open Settings

---

# 4. Map Flow 🗺️

Open Map

Display:

- Driver location
- Road name
- Speed
- Hotspot areas
- Service locations

Driver actions:

- Search destination
- Start navigation
- Save location

---

# 5. Navigation Flow 🚦

Select destination

↓

Calculate route

↓

Show:

- Route line
- Distance
- Next turn
- Voice guidance

During driving:

- Speed monitoring
- Safety warnings
- Route updates

---

# 6. Ride Tracking 📊

During ride:

Collect:

- Distance
- Time
- Route
- Estimated fare

After ride:

Save:

- Ride history
- Earnings
- Distance data

---

# 7. Fuel Tracking ⛽

Driver enters fuel details:

- Fuel amount
- Fuel cost

System calculates:

- km/L
- Fuel efficiency
- Daily fuel cost

---

# 8. Hotspot Flow 🔥

Open Hotspot Map

Show:

- High demand areas
- Medium demand areas
- Good areas

Driver can:

- Save places
- Check area history

---

# 9. Settings Flow ⚙️

Manage:

- Vehicle details
- Language
- Voice settings
- Map settings
- Safety alerts
- Notifications

---

# 10. Data Backup 💾

Store:

- Driver profile
- Ride history
- Fuel records
- Settings

Future:

- Cloud backup
- Account restore

---

# Goal

Create a simple and safe workflow that helps drivers complete daily work faster.
