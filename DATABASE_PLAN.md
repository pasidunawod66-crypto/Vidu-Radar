# Vidu Radar Database Plan 💾🚕

## Database System

Firebase Database will be used to store and manage app data.

---

# 1. Driver Profile 👤

Store:

- Driver ID
- Name
- Phone number
- Vehicle number
- Vehicle type
- Preferred language
- Account settings

---

# 2. Vehicle Data 🚕

Store:

- Vehicle type
- Fuel type
- Fuel price
- Average km/L
- Maintenance information

---

# 3. Location Data 📍

Store:

- Current location
- Saved locations
- Favorite places
- Work areas

---

# 4. Hotspot Data 🔥

Store:

- Location name
- Latitude
- Longitude
- Demand level

Demand levels:

- High demand
- Medium demand
- Good area

Additional:

- Time based demand
- Area history
- Driver feedback

---

# 5. Ride History 📊

Store:

- Date
- Start location
- Destination
- Distance
- Fare
- Time taken

---

# 6. Fuel Records ⛽

Store:

- Fuel amount
- Fuel price
- Date
- Distance traveled
- km/L calculation

---

# 7. Earnings Data 💰

Store:

- Daily income
- Weekly income
- Monthly income
- Fuel expenses
- Profit calculation

---

# 8. Service Locations 🔧

Store:

- Fuel stations
- Banks
- Garages
- Tyre shops
- Spare parts shops
- Three-wheel repair places

Data:

- Name
- Location
- Contact details
- Opening hours

---

# 9. App Settings ⚙️

Store:

- Language settings
- Voice settings
- Map settings
- Notification settings
- Safety settings

---

# Future Database Features

- Offline data storage
- Cloud backup
- Driver reports
- Smart demand prediction
