# Vidu Radar Project Plan 🚕🔥

## Smart Driver Assistant App

Vidu Radar is a smart driver assistant app designed to help drivers save fuel, time and increase daily income.

---

# 1. Navigation System 🗺️

Features:

- Google Maps / Navigation SDK
- Live GPS location
- Turn-by-turn navigation
- Sinhala + English voice guidance
- Road name display
- Speed display
- Route tracking
- Real-time direction assistance
- Distance to destination
- Next turn information

---

# 2. Smart Hotspot Map 🔥

Features:

- High ride locations display
- Demand based color system

Colors:

- 🔴 High demand area
- 🟡 Medium demand area
- 🟢 Good driving area

Additional:

- Time-based hotspot prediction
- Driver saved locations
- Popular ride areas
- Area history data

---

# 3. Driver Dashboard 🚕

Information display:

- Current speed
- Today's total km
- Driving time
- Number of trips
- Total earnings
- Fuel usage
- Fuel cost

---

# 4. Fuel Monitor ⛽

Features:

- Fuel tracking
- Fuel cost calculation
- km per liter calculation
- Fuel efficiency status

Fuel status:

- 🟢 Good fuel saving
- 🟡 Normal usage
- 🔴 High fuel consumption

Vehicle settings:

- Vehicle type
- Fuel type
- Average km/L
- Fuel price

---

# 5. Fare Calculator 💰

Features:

- Base fare setting
- Per km charge
- Waiting time charge
- Fuel cost calculation
- Profit estimation

---

# 6. Driver Helper Locations 📍

Map markers for:

- ⛽ Fuel stations
- 🏦 Banks
- 🔧 Garages
- 🛞 Tyre shops
- 🔩 Spare parts shops
- 🛺 Three-wheel repair places

---

# 7. Safety Voice Assistant 🔊

Languages:

- Sinhala
- English

Alerts:

- Speed limit warning
- Turn warnings
- Signal reminders
- Sharp turn warning
- Safety messages
- Rest reminders

Example:

"වේගය අඩු කරන්න. ඉදිරියේ වංගුවක් ඇත."

---

# 8. Floating Assistant Bubble 📱

Small overlay assistant:

Display:

- Speed
- Current road
- Next turn
- Fare information
- Quick buttons

---

# 9. Advanced Navigation 🚦

Features:

- Thick route line
- Auto zoom at turns
- Day/Night mode
- 3D map view
- Route tracking
- Shortest route
- Fuel saving route

---

# 10. Settings System ⚙️

Driver profile:

- Driver name
- Vehicle details
- Vehicle number

Map settings:

- Map style
- Show hotspots
- Show service locations

Voice settings:

- Language selection
- Voice volume
- Warning settings

Notification settings:

- Ride alerts
- Hotspot alerts
- Fuel alerts

---

# 11. Database System 💾

Store:

- Driver profile
- Hotspot locations
- Saved places
- Service locations
- Ride history
- Fuel records
- Earnings data

---

# Technology Stack 💻

- Flutter + Dart
- Firebase Database
- Google Maps Platform
- OpenStreetMap support
- Text-to-Speech System
- Location Services

---

# Goal 🎯

Create a simple, low-cost smart assistant to help drivers save fuel, save time and improve daily income.
