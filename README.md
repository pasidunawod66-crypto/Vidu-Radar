# Vidu Radar 🚕🔥

## Smart Driver Assistant App

A smart assistant app designed to help drivers save fuel, time and improve daily income.

## Features

### 1. Navigation System
- Google Navigation SDK for Android
- Live GPS location
- Turn-by-turn navigation
- Voice guidance (Sinhala + English)
- Road name display
- Speed display
- Route tracking

### 2. Smart Hotspot Map
- High ride locations display
- 🔴 High demand
- 🟡 Medium demand
- 🟢 Good area
- Time-based hotspot prediction
- Driver saved locations

### 3. Fare Calculator
- Base fare setting
- Per km charge setting
- Waiting time charge
- Fuel cost calculation
- Profit estimation

### 4. Driver Helper Locations
- ⛽ Fuel stations
- 🏦 Banks
- 🔧 Garages
- 🛞 Tyre shops
- 🔩 Spare parts shops
- 🛺 Three-wheel repair places

### 5. Safety Voice Assistant
- Speed limit warning
- Turn warnings
- Signal reminders
- Safety messages

### 6. Floating Assistant Bubble
- Speed
- Current road
- Next turn
- Fare information
- Quick access buttons

## Technology
- Flutter + Dart
- Firebase Database
- Google Maps / OpenStreetMap
- Text-to-Speech Voice System

## Goal
Create a simple, low-cost smart assistant to help drivers.
