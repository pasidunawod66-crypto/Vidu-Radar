# Vidu Radar User Manual 🚕🔥

## Smart Driver Assistant Guide

Vidu Radar helps drivers save fuel, time and manage daily driving activities.

---

# 1. Getting Started 🚕

Open the app:

1. Create driver profile
2. Add vehicle details
3. Select language
4. Set fuel information
5. Start using the assistant

---

# 2. Home Screen 🏠

The home screen shows:

- Current location
- Online status
- Current speed
- Today's distance
- Fuel status
- Earnings summary

Quick access:

- Map
- Hotspot
- Fare Calculator
- Dashboard
- Settings

---

# 3. Using Navigation 🗺️

Steps:

1. Open Map
2. Search destination
3. Select route
4. Start navigation

The app provides:

- Route guidance
- Next turn information
- Road names
- Voice instructions

---

# 4. Hotspot Map 🔥

Hotspot colors:

🔴 High demand area

🟡 Medium demand area

🟢 Good area

Drivers can:

- Check busy locations
- Save useful places
- Plan routes

---

# 5. Fare Calculator 💰

Enter:

- Base fare
- Distance charge
- Waiting charge

The app calculates:

- Estimated fare
- Fuel cost
- Expected profit

---

# 6. Fuel Monitor ⛽

Add:

- Fuel amount
- Fuel price

The app shows:

- Fuel usage
- km/L
- Fuel efficiency

---

# 7. Safety Assistant 🔊

Provides alerts:

- Speed warnings
- Turn warnings
- Safety reminders
- Voice guidance

---

# 8. Service Locations 📍

Find nearby:

- Fuel stations
- Banks
- Garages
- Tyre shops
- Spare parts shops
- Repair places

---

# 9. Settings ⚙️

Manage:

- Vehicle details
- Language
- Voice settings
- Map settings
- Notifications
- Safety alerts

---

# 10. Privacy & Safety 🔒

Users control:

- Location permission
- Account data
- App settings

# Goal

Make daily driving easier, safer and more efficient.
